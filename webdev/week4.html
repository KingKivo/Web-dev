Week 4


Games programming

In our fourth week of games programming, we looked into setting up the library known as SDL or Simple Direct Media Layer 2. We needed to get this set up and get familiar with it as this is the library we would be using when developing out pacman game which is a required submission at the end of week 14. Essentially it allowed us to make use of precompiled libraries draw 2D graphics on the screen which allowed for us to see what our code was actually doing on the screen. We made out own entities saving them as bitmaps to use on the screen to control the character and then code the enemy that is supposed to chase you.
